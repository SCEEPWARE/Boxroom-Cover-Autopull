# Boxroom Cover Autopull
This mod re-enables the automatic cover art pulling feature from the demo.<br>
Requires BepInEx. More instructions for its installation [here](https://docs.bepinex.dev/articles/user_guide/installation/index.html).

## Installation
Drop the DLL file (either by downloading from releases or by building it yourself) in the BepInEx/plugins folder.

## Notes
Expect lag when launching the game, as the cover arts load.<br>
I don't know if this was also present in the demo as I didn't play it.
